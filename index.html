Separate an early-warning indicator from actual outcomes. The distinction matters for the decisions an executive makes next.

Shipping time gap

The dataset's average actual shipping duration exceeds its scheduled duration. These are order-item-level averages from the documented report.

Risk is not the outcome

One dataset field flags order items that carry late-delivery risk. That is different from the separately reported delivery-status measure.

54.83%Flagged
Flagged for late-delivery risk Not flagged by this risk field
Do not interpret 54.83% as the percentage actually delivered late. The SQL model calculates confirmed late-delivery percentages from delivery_status separately.

Where should leaders investigate first?

Compare shipping modes and delivery statuses in the original report, then validate whether high risk flags correspond to actual late deliveries before choosing an intervention.

Initial profiling found no exact duplicate rows. The cleaned dataset retains 180,519 rows across 45 analytical columns. Personal identifiers were excluded from the core analytical dataset; source-data quality limitations remain documented.

Read quality report ↗
Methodology and limits: All reported values are historical and approximate, as published in the repository README. Source currency is not specified here. The dataset's reported profit metric is not independently verified accounting profit; some order-level profit values may repeat across item rows. Late-delivery risk is not confirmed late delivery. January 2018 is a partial month. Segment shares use three rounded figures, so rounding differences are expected. This site is a visual case study, not a live feed or forecasting model.
